# Manuscript Theory Model Notes

This note is the working reference for the computational-study narrative in the
manuscript and Supporting Information. It separates three layers that should not
be mixed in the final writing:

1. SCUFF-EM full-geometry field checks.
2. `pss4_project` local sidewall fluctuational-electrodynamics calculations of
   `h_W(T)`.
3. A one-dimensional non-isothermal slab/fin heat-transfer model that converts
   `h_W` into a device-level effective coefficient.

## Notation

Use these symbols consistently in manuscript text, SI, figures, and code:

| Symbol | Meaning |
| --- | --- |
| `W` | slab/fin width along the sidewall-normal `x` direction |
| `H` | slab/fin height along `y` |
| `d` | vertical offset between the opposing slab roots |
| `H - d` | overlap length; avoid `Lov` in final text unless first defined |
| `delta` | vacuum gap between opposing sidewalls before coating |
| `d_eff` | remaining vacuum gap after conformal coating |
| `h_W` | local sidewall heat-transfer coefficient from pss4 |
| `h_ptp` | tip-to-opposite-stem planar coefficient |
| `k_SiN` | axial thermal conductivity used for the solid slab |
| `T_H(y), T_C(y)` | hot-side and cold-side slab temperatures |

## Model Chain

### 1. SCUFF-EM Field Check

SCUFF-EM is used on selected full interpenetrating geometries, not as the main
parameter-sweep engine. Its role is to establish that, inside the overlap
region, the vacuum-gap flux is dominated by the sidewall-normal component:

```text
q_rad approximately q_x
```

This supports reducing the interpenetrating region to local sidewall junctions.
The SCUFF-EM section should report:

- geometry groups and dimensions;
- boundary-element mesh origin and element counts;
- material file used for SiO2, including `poy/materials/silica-27p.txt`;
- evaluation points and frequency points;
- Poynting-vector component definition and sign convention.

SCUFF-EM output is still being computed, so this part should remain a placeholder
until the `results/` files are available.

### 2. pss4 Local Sidewall Coefficient

pss4 models the local sidewall junction as a planar periodic stack normal to
`x`. For an uncoated sidewall:

```text
PERIODIC_BOUNDARY
SiN | Vacuum(d_eff) | SiN
PERIODIC_BOUNDARY
```

For a coated sidewall:

```text
PERIODIC_BOUNDARY
SiN | SiO2(coat) | Vacuum(d_eff) | SiO2(coat) | SiN
PERIODIC_BOUNDARY
```

The solver computes polarization-resolved transmission probabilities
`tau_mu(omega,k_parallel)` and integrates over in-plane wavevector:

```text
Phi(omega) =
  sum_mu int_0^infty tau_mu(omega,k_parallel)
  k_parallel dk_parallel / (2*pi)
```

The local sidewall coefficient is then:

```text
h_W(T) =
  int_0^infty [dTheta(omega,T)/dT] Phi(omega) domega / (2*pi)
```

where:

```text
Theta(omega,T) = hbar omega / [exp(hbar omega / k_B T) - 1]
```

The manuscript Methods should include this compact equation. SI should include
the pss4 stack files, material files, grids, and representative `tau`/spectral
flux outputs.

### 3. Non-Isothermal Slab Model

The slab model uses the pss4 value `h_W` as a local radiative exchange
coefficient and solves for the axial temperature profiles.

The model has three regions in the coordinate `y`:

- Region 1: `0 <= y <= d`, hot slab only.
- Region 2: `d <= y <= H`, overlapping hot and cold slabs coupled by sidewall
  NFRHT.
- Region 3: `H <= y <= H + d`, cold slab only.

The base temperatures are:

```text
T_H(0) = T_H0
T_C(H + d) = T_C0
```

In the non-overlap regions:

```text
d^2 T_H / dy^2 = 0
d^2 T_C / dy^2 = 0
```

In the overlap region, with two active sidewalls per slab:

```text
k_SiN W d^2 T_H / dy^2 =  2 h_W [T_H(y) - T_C(y)]
k_SiN W d^2 T_C / dy^2 = -2 h_W [T_H(y) - T_C(y)]
```

Equivalently, for `theta(y) = T_H(y) - T_C(y)`:

```text
d^2 theta / dy^2 = beta^2 theta
beta = sqrt(4 h_W / (k_SiN W))
L_th = 1 / beta = sqrt(k_SiN W / (4 h_W))
```

`L_th` is the penetration length over which a nonzero temperature difference can
be sustained between the opposing sidewalls. When `H - d << L_th`, the active
area grows approximately linearly with overlap. When `H - d >> L_th`, the
central overlap approaches local thermal equilibrium and the device conductance
saturates.

Tip coupling can be represented by a semi-infinite planar coefficient:

```text
q_tip = h_ptp [T_tip - T_opposite_stem]
```

Use `h_ptp` from a semi-infinite material-vacuum-material calculation. The
opposite stem temperature is set to 295 K or 300 K according to whether the
boundary faces the cold or hot stem.

The device-level heat flow is obtained from the conductive heat flux at the
slab bases after solving the boundary-value problem. The effective coefficient
is then:

```text
h_eff = Q / (A_FP Delta T_global)
```

where `A_FP` is the experimental projected footprint used for normalization.

## Approximations To State Explicitly

1. `h_W` is treated as locally constant inside one thermal-model solve.
   The maximum experimental slab temperature swing is about 5 K, and this
   should be checked by evaluating `h_W(T)` over the relevant 295-300 K range.
2. Lateral temperature variation across one slab width is neglected because
   `W << H` in the high-aspect-ratio devices and the cross-width conduction
   time/length scale is small compared with the axial direction.
3. The axial solid conduction is modeled using a SiN thermal conductivity,
   because heat conduction in the SiO2-coated-on-SiN slab is dominated by the
   SiN core. The numerical value must be defined in code as a configurable
   parameter, not as an inline constant.
4. The local sidewall pss4 model neglects fin tips and roots; SCUFF-EM maps are
   used to justify that the dominant overlap-region flux is sidewall-normal.
5. The wavevector-resolved transmission map is a local planar-junction
   diagnostic and should not be described as a full finite-geometry
   wavevector-resolved result.
